# Apla Ganesha Group Website

## Apps you need
1. Visual Studio Code
2. Google Chrome (or Firefox)
3. Git (optional for now)

You do NOT need a complicated framework to start.

## How to run
- Extract this folder.
- Open it in VS Code.
- Install the VS Code extension "Live Server".
- Right-click `index.html` → "Open with Live Server".
- Your website opens in the browser.

## How to edit the site
Open `admin.html` in the browser.
You can change:
- Hero banners
- Banner text
- YouTube channel link
- YouTube videos
- About text
- Next event/date

IMPORTANT: The Admin page currently saves changes in your browser's localStorage. This is perfect for learning/testing, but it is NOT a real online admin system.

## Adding local photos
Put your photos inside `assets/`, for example:
assets/banner1.jpg
assets/jhakri1.jpg

Then use those paths in Admin.

## Next upgrade
When the design is finished, connect the site to Firebase or Supabase so your admin changes can update the public website for everyone online.
