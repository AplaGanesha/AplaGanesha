# Apla Ganesha Group Website

Premium responsive website for Apla Ganesha Group.

## What's included
- Responsive mobile/desktop layout with working mobile navigation
- Admin page with browser-based password lock
- Custom YouTube thumbnails per video
- Automatic YouTube thumbnails when a custom thumbnail is not supplied
- Editable hero banners
- Editable YouTube videos
- Editable gallery photos
- Editable event + countdown
- Editable YouTube, Instagram, TikTok and Facebook links
- LocalStorage-based admin editing (no backend required)

## Important admin-lock note
This is a static GitHub Pages website. The Admin lock is a **browser-side convenience lock**, not true server authentication. Do not use a sensitive password and do not treat it as protection for confidential information.

## How to use Admin
1. Open `admin.html`.
2. On first visit, create an admin password (6+ characters recommended).
3. Edit your content and click **Save changes**.
4. The changes are stored in that browser's LocalStorage.
5. For a custom video thumbnail, paste an image URL/path in the thumbnail field.

## GitHub Pages
Upload the website files to your repository and enable GitHub Pages from the repository's Pages settings.
